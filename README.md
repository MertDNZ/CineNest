# Cine Nest

<p align="center">
CineNest is an application built with the Flutter framework and clean architecture pattern, where you can discover movies. <br>
<a href="https://www.themoviedb.org/"> The Movie Database API </a> is used for the data source
</p>

## Main Screen

On this screen you can see:

- Trending Movies
- Popular Movies
- Top Rated Movies

## Detail Screen && Search Feature

You can search movies by keywords and directed to detail screen.
<br>On detail screen you can see detailed information about the movie, casts and related videos.

- Detailed Information
- Related Videos (Trailers Etc.)
- Casts
- Search Feature
